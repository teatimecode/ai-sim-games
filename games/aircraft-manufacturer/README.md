# 适航 · Airworthiness

一款用浏览器玩的飞机制造经营模拟。你是北辰航空 P-19 支线喷气项目的总师，在 18 个季度里把一架飞机送过五道门：设计冻结 → 首架试飞机下线 → 首飞 → 型号合格证 TC → 生产许可证 PC，然后交付 25 架。

纯前端静态站点，无框架、无依赖、无网络请求、无构建步骤。

## 快速开始

```bash
cd games/aircraft-manufacturer
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

必须用 HTTP 打开，不能直接双击 `index.html`（`file://` 下浏览器的模块与字体行为不一致）。

## 玩法

### 每一季你要做的四件事

1. **技术流程**：把五个部门的产能派到工作项上。部门不能互相借人，工作项有前置依赖。
2. **产线**：加班提产、投扩线（两季后第二个总装位投产）、转租机位。
3. **采购**：锁定发动机，30% 预付，三季后到货，只能整批。
4. **商务**：接单或拒单，看窗口和折扣。

做完点「提交本季」，世界结算，结果不可逆。

### 五道门

| 门 | 满足条件 | 现实对应 |
|---|---|---|
| G1 设计冻结 | 系统布置与数字样机、CDR 评审 | Critical Design Review |
| G2 首架试飞机下线 | 工装型架、首件总装 | 首件与专用工装 |
| G3 首飞 | 首架试飞机 + 铁鸟台联试 | Iron Bird 系统联调 |
| G4 TC 型号合格证 | 静力、疲劳、包线、失速颤振、噪声结冰，再转成符合性文件 | Type Certificate |
| G5 PC 生产许可证 | 局方确认你能稳定产出合格飞机 | Production Certificate |

**TC 与 PC 是两件事**：拿到 TC 说明设计可以载客，拿到 PC 才能交付。中间至少要空转一季——产线在造，现金在烧，一架上不了航线。

### 五个部门

设计部、制造工程、试验部、试飞部、适航部。试飞部按**架次**算产能，每季只有 2–4 个。

### 胜负

| 结果 | 条件 |
|---|---|
| 通关 | 第 18 季结束时累计交付 ≥25 架且现金 >0 |
| 降级为技术验证机 | 交付 15–24 架 |
| 项目终止 | 交付 <15 架 |
| 破产 | 任一时刻现金 < −3 亿 |

### 辅助工具

- **引导模式**（默认开，HUD 可关）：每季列 1–5 条可一键执行的动作。
- **关键路径条**：到下一道门还差哪几项，实心点表示现在就能动。
- **预测**：按现有产能往后推 12 季，给 TC / PC / 首架交付 / 现金最低点——算的是「不追加投入的代价」。
- **自动派工**：按关键路径优先填满产能。
- **图鉴**：15 件部件的线稿、规格与作用。

### 序章与立项

开局有 8 屏背景：公司、上一款机型、行业格局、前任总师、董事会目标、团队，最后是两个立项选择——站哪个座级（96 / 130 座）、怎么造（全新设计 / 改型衍生）。两个选择都会改变开局数值。其中四屏配有线稿插图（厂区、车间、董事会、首飞）。

进入第 1 季后，界面顶部会出现**新手目标清单**，用祈使句告诉你每季该点哪里（选融资 → 派工 → 提交 → 锁发动机 → 接单 → 扩线）。第 5 季自动消失，也可以点「知道了」提前关掉。

## 测试

```bash
cd games/aircraft-manufacturer
node qa/verify.mjs
```

退出码 0 表示通过。它会：

1. 在真实引擎上跑主线与三条失败分支；
2. 校验立项变体、情节节拍、决策辅助接口；
3. 校验 `qa/evidence/run.json` 与当前构建哈希一致、实机截图存在且非空；
4. 整份重写 `qa/verification.json`（失败时也重写，不残留旧 PASS）。

预期输出：

```
build <hash>
main  : win 31 2.24 TC 12 PC 13
noHire: fail 14 TC 15
noFly : fail 12 TC 13
greedy: fail 6
verification.json written, status PASS
```

`qa/evidence/` 里的截图和 `run.json` 是上一次在 Chromium 1440×900 下真实点击跑完 18 季的记录。**改动 `index.html` / `engine.js` / `ui.js` / `game.css` / `codex.js` 后哈希会变，`verify` 会报「实机记录与当前构建不一致」**，这时需要重新跑一次实机并更新 `qa/evidence/`。

## 边界

- 无后端、无账号、无内购、无遥测。
- 不含任何真实厂商的商标、涂装、机型照片或手册文本；名称与代号均为虚构。
- 音效未实现，纯静音可玩。
- 第三章「航天延伸」只有设计说明，没有实现。
