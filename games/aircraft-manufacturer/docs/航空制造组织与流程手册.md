# 航空制造的组织与流程手册

> 用途：配《适航》游戏阅读。游戏里每张任务卡对应这里一个真实环节。读懂这份手册，你就知道为什么"签了订单也交不出飞机"。
> 口径：部门设置与流程按主流整机厂（OEM）与航司的通行做法整理，具体公司会有差异，但骨架一致。术语首次出现给中英对照。

---

## 一、先分清两种公司

很多人把它们混为一谈，其实是两门完全不同的生意。

| | 整机制造商（OEM） | 航空公司（Airline） |
|---|---|---|
| 卖什么 | 飞机，以及它未来 30 年的备件与服务 | 座位，按航段销售 |
| 收入节奏 | 交付时一次性确认大头，服务费长期细水长流 | 每天现金流，客座率决定生死 |
| 核心资产 | 型号合格证、工装、供应链关系 | 机队、航权、常旅客 |
| 死法 | 型号取证失败、产能爬不上去、现金流断 | 油价暴涨、需求塌陷、安全事故 |

本作让玩家坐在左边那把椅子上。右手的逻辑只作为"客户需求"出现。

## 二、整机制造商的部门

一家做干线/支线飞机的整机厂，组织大致如下。注意：**部门是按"专业能力"划分的，不是按项目划分的**；项目（比如 P-19）是横着切过所有部门的。

### 2.1 工程与研发

| 部门 | 负责什么 | 交付物 |
|---|---|---|
| 气动与总体 | 外形、机翼平面形状、性能初算 | 外形数模、性能手册初稿 |
| 载荷与结构 | 飞行/地面载荷、机体结构、疲劳寿命 | 载荷报告、结构数模、疲劳评定 |
| 系统集成 | 飞控、液压、燃油、电气、航电的布置与接口 | 系统原理图、数字样机 DMU |
| 客舱与内饰 | 座椅、行李架、厨房、卫生间、应急撤离 | 客舱布置图、撤离演示 |
| 重量与平衡 | 空重控制、重心包线 | 重量清单、载重平衡手册 |
| 适航工程 | 把设计证据翻译成局方认可的文件 | 审定计划、符合性文件 |

其中"重量控制"是最容易被外行忽略、也最能毁掉项目的部门：每超重 1%，航程和载客量都要打折，销售当场就要重谈价格。

### 2.2 制造

| 部门 | 负责什么 |
|---|---|
| 制造工程 | 工装、型架、装配工艺、节拍设计 |
| 工装与设备 | 专用工装的设计、制造、校准 |
| 总装 | 四条主线：前段对接、机翼装配、系统安装、喷漆交付 |
| 部装/零件 | 机身筒段、机翼盒段、复材件 |
| 质量 | 不符合项处理、返工、放行签字 |
| 供应链 | 长周期件（发动机、起落架、航电）的锁定与跟催 |

真实的瓶颈几乎永远不在"总装工人不够"，而在**工装没到位**或**某个长周期件没到**。

### 2.3 试验与试飞

| 部门 | 负责什么 | 典型设施 |
|---|---|---|
| 结构与强度试验 | 静力试验（加载到 150% 极限载荷）、疲劳试验（两倍寿命） | 静力试验台、疲劳试验台 |
| 系统集成试验 | 铁鸟台（Iron Bird）联试：飞控、液压、起落架在实物台架上联调 | 铁鸟台 |
| 环境试验 | 结冰风洞、噪声、电磁兼容 | 风洞、微波暗室 |
| 试飞 | 首飞、包线扩展、失速/尾旋、颤振、性能、噪声、高原高温、结冰 | 试飞基地、遥测站、 chase 机 |

试飞部按**架次**算产能，不按人头。一个型号的取证试飞通常是几百到上千架次；本作把它压缩成 11 个架次的关键科目。

### 2.4 适航与取证

| 角色 | 做什么 |
|---|---|
| 适航部 | 与局方（中国 CAAC / 美国 FAA / 欧洲 EASA）对接，提交审定计划（PSAC）与符合性计划（CP） |
| 符合性验证 | 把每一项试验/试飞结果整理成符合性文件（MOC，Method of Compliance） |
| 问题单（Issue Paper） | 局方提出的疑问，必须逐条闭环，否则不颁证 |
| 生产许可 | 证明你不是"造出一架好飞机"，而是"能稳定地造出每一架合格飞机" |

### 2.5 商务与客户

| 部门 | 负责什么 |
|---|---|
| 销售 | 谈单、折扣、交付窗口、违约条款 |
| 合同与金融 | 预付货款（PDP）排期、出口信贷、租赁结构 |
| 客户支持 | 备件、AOG（飞机停场待件）响应、技术代表驻场 |
| 持续适航 | 服务通告（SB）、适航指令（AD）的执行与跟踪 |

## 三、航空公司的部门

如果你要理解"客户为什么这么砍价"，需要知道对面坐的是谁。

| 部门 | 负责什么 | 对制造商的影响 |
|---|---|---|
| 机队规划 | 未来 5–10 年买什么座级、买多少 | 决定订单的座级与数量 |
| 采购与合同 | 谈价格、折扣、交付窗口、违约条款 | 你的折扣与交付压力来自这里 |
| 财务与融资 | 自购、融资租赁、经营租赁的选择 | 决定付款结构与 PDP 节奏 |
| 运行控制（AOC） | 排班、机组、签派 | 交付晚一天，排班就要重排 |
| 机务维修（MRO） | 定检、AOG、备件 | 售后能力差的厂商会被扣分 |
| 客舱服务 | 座椅密度、厨房、娱乐系统 | 内饰定制化会拖垮你的节拍 |
| 安全与质量 | 事件调查、适航指令执行 | 一次停飞能让整个机队停场 |

一个常被忽略的事实：**航司买飞机时看的不是目录价，而是"每座每公里成本"**（CASK）。所以你的座级、油耗、维修成本、残值，最后都会被折算成同一个数字来比较。

## 四、一架飞机从纸面到航线的六段路

```
概念 → 设计 → 制造 → 地面试验 → 试飞 → 取证 → 量产与投入运营
```

| 阶段 | 关键动作 | 门（Gate） | 卡住会怎样 |
|---|---|---|---|
| 概念与立项 | 市场定位、座级选择、研制方案 | 立项评审 | 选错座级，后面全错 |
| 详细设计 | 气动冻结、载荷、结构、系统布置、数字样机 | **CDR 设计冻结** | 设计没冻结，工装不能开工 |
| 制造 | 工装型架、首件、总装 | **首架试飞机下线** | 没有实物，试验和试飞都做不了 |
| 地面试验 | 静力、疲劳、铁鸟台联试 | 试验通过 | 试验不过，设计要回改 |
| 试飞 | 首飞、包线扩展、失速颤振、性能、噪声结冰 | **首飞 / 试飞科目完成** | 科目不过，包线打不开 |
| 取证 | 符合性文件归档、问题单闭环 | **TC 型号合格证** | 没 TC，一架都不能交 |
| 量产 | 生产许可审核、产能爬坡、交付、投入运营（EIS） | **PC 生产许可证** | 没 PC，造出来也只能停在停机坪 |

### 4.1 TC 与 PC 的区别，是本作最重要的一课

- **TC（Type Certificate，型号合格证）**：证明**这个设计**符合适航标准。拿到 TC，说明"这个型号可以载客"。
- **PC（Production Certificate，生产许可证）**：证明**你的生产线**能稳定复制出符合设计的飞机。拿到 PC，说明"你造的每一架都可信"。

现实里，TC 之后到 PC 之间往往还有几个月到一年。这段时间飞机可以造，但不能交付——**这就是账面现金和真实回款之间那道最要命的缝**。

### 4.2 取证之后还没完

| 名词 | 含义 | 谁的痛 |
|---|---|---|
| EIS（Entry Into Service） | 首架投入商业运营 | 你的售后团队开始 24 小时待命 |
| SB（Service Bulletin） | 厂家发的服务通告，建议性 | 客户可以选做或不做 |
| AD（Airworthiness Directive） | 局方强制指令，必须执行 | 不做就停飞，做就赔钱 |
| 可靠性数据 | 机队运行数据回流 | 决定下一代设计改哪里 |

## 五、把流程映射到游戏

| 游戏里的门 | 真实对应 | 你要动的部门 |
|---|---|---|
| G1 设计冻结 | CDR（Critical Design Review） | 设计部 |
| G2 首架试飞机下线 | 首件总装 + 工装就绪 | 制造工程 |
| G3 首飞 | 首飞 + 铁鸟台联试 | 试验部、试飞部 |
| G4 TC | 静力/疲劳/包线/失速颤振/噪声结冰 + 符合性文件 | 试验部、试飞部、适航部 |
| G5 PC | 生产许可审核 | 适航部 |

游戏把"几百个架次、上千份文件"压缩成 19 个工作项、5 个部门、18 个季度。压缩的是数量，不是因果：**每一个卡点都对应现实里真实存在的卡点**。

## 六、想继续深入，按这个顺序看

1. **先看流程**：任何一本适航入门（如 FAA 的 Type Certification 流程说明）都能让你明白 TC/PC 的分工。
2. **再看组织**：找一份整机厂的年报，看它的部门划分与研发投入占比。
3. **再看瓶颈**：搜"航空供应链 发动机 交付延迟"，你会看到本作第 12 季那张停线图在现实里的样子。
4. **最后看商业**：搜"PDP pre-delivery payment"，理解为什么整机厂现金流是"客户的钱在养你的产线"。

## 七、术语速查

| 缩写 | 全称 | 一句话 |
|---|---|---|
| CDR | Critical Design Review | 设计冻结评审 |
| DMU | Digital Mock-Up | 数字样机，用来查干涉 |
| MOC | Method of Compliance | 符合性方法，说明你怎么证明合规 |
| PSAC | Proposed Special Conditions / Certification basis | 审定基础建议 |
| TC | Type Certificate | 型号合格证 |
| PC | Production Certificate | 生产许可证 |
| STC | Supplemental Type Certificate | 改装补充型号证 |
| EIS | Entry Into Service | 投入商业运营 |
| PDP | Pre-Delivery Payment | 交付前付款 |
| AOG | Aircraft On Ground | 飞机停场待件 |
| SB / AD | Service Bulletin / Airworthiness Directive | 服务通告 / 适航指令 |
| CASK | Cost per Available Seat Kilometer | 每座每公里成本 |
