# PRODUCT_BRIEF — 《适航》

## 1. 来源与位置

本项目不是小说改编，原料是**现实产业**：`SOURCE_BIBLE.md` 已经完成了原作在小说改编流程里的位置 —— 它提供"世界设定、势力结构、冲突与代价"。因此本文件锁定的是用户已明确表达的限制，其余维度在概念阶段收敛。

## 2. 已锁定（用户明确表达，不可擅改）

| 维度 | 锁定值 | 出处 |
|---|---|---|
| 主题 | 模拟「飞机制造厂商」经营：生产制造、销售、运营流程，并延伸到航天 | 用户原话 |
| 学习目的 | 玩家要能"代入了解"不同公司的飞机与航天制造/销售运营流程，理解为什么这样运作 | 用户原话 |
| 品牌 | 公司名与机型名全部去品牌化；世界由虚构厂商构成 | 用户原话 |
| 用途 | 个人学习，非商业发布，不涉及商业授权 | 用户原话 |
| 现实性底线 | 保留产业结构与流程因果的真实性，改掉身份标识 | 由"学习用途"推出 |
| 语言 | 简体中文 | 对话语言 + UI locale |
| 平台 | 桌面 Web，键鼠 | 概念阶段选定（见 CONCEPT） |
| 单人 | 单人离线，无联网、无内购、无社交 | 学习用途约束 |

## 4. 预算与范围上限

| 项目 | 上限 |
|---|---|
| 首个可玩版本 | 1 条完整通关路径，12 个回合，约 60–90 分钟 |
| 系统数量 | 6 个（规格/供应链/生产/取证/商务/财务），不做第 7 个 |
| 内容量 | 1 个机型项目 + 1 个改型项目 + 1 个航天延伸章节（可只到接口） |
| 美术 | 无 3D 模型工厂；等轴测示意图 + 工业信息界面，资产可降级为矢量化图形 |
| 无授权依赖 | 不使用任何真实厂商素材，全部原创矢量与文本 |

## 5. 不可妥协的体验底线

1. 玩家必须在第一回合就看见"订单多 ≠ 交付多"，并在第十二回合亲手算出两者为什么不同。
2. 每一次交付延误都必须能追溯到玩家自己做过的某个决定，而不是纯随机。
3. 玩家关掉游戏后能用自己的话讲出：一架飞机从立项到进入航司机队，卡在哪几个环节、每个环节谁说了算。
4. 去品牌化不能变成"换皮模板"：遮掉虚构名，剩下的必须是真实的产业结构。
