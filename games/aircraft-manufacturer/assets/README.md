**压缩**：JPEG，质量 80–85，单文件 ≤ 400 KB，sRGB，去 EXIF。
单张上限 2 MB（超过会被浏览器拖慢首屏）。

**风格**：纪实摄影或写实概念图；真实比例与材质；自然光或工业混合光；低饱和。
**禁止**：商标、涂装、真实航空公司标识、可辨认的真实厂名、水印、文字标语。

## 加载规则

- `<img>` 加载失败时触发 `onerror`，容器加 `.noimg` 类，显示内置线稿。
- 头像同理：`assets/assistant.jpg` 失败则用内置矢量头像。
- 照片统一加滤镜 `saturate(.78) contrast(1.04) sepia(.12)` 融进纸面。
- 不需要改代码、不需要重新构建；放文件、刷新即可。
