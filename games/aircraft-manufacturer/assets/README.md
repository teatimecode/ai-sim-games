# 序章照片

游戏会优先加载这里的照片；某个文件不存在时，自动回退到内置线稿，不会出现空图。

| 文件 | 用在哪 | 建议 |
|---|---|---|
| `prologue-yard.jpg` | 序章第 1 屏（厂区）、情节「第一位客户走进车间」 | 横向 16:9，≥1280×720 |
| `prologue-shop.jpg` | 序章第 2 屏（车间）、情节「老周的笔记本」备选 | 同上 |
| `prologue-notebook.jpg` | 序章第 4 屏（前任总师）、情节「老周的笔记本」 | 同上 |
| `prologue-board.jpg` | 序章第 5 屏（董事会）、情节「董事会前夜」 | 同上 |
| `prologue-runway.jpg` | 情节「首飞」 | 同上 |

放置后无需改代码，刷新页面即生效。照片会统一加一层低饱和与暖色滤镜（`saturate .78 / sepia .12`），与纸面界面融合。
