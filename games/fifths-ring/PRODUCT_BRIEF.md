# PRODUCT_BRIEF —《对位学徒》

改编材料：Open Music Theory（openmusictheory.github.io），开源音乐理论教材，CC BY-SA。

## 一句话定位

把整本教材装进一座由音程承重的城：玩家是记谱学徒，用补谱、拼音阶、平和声账、测音集四类动作，把六个城区走完。每一章都有一张可读的讲解卡，每一处判定都引用教材原文。

## 范围变更

首版只做了对位一章的四关。第二轮扩到"通过游戏经历全部知识"，新增世界观、五个虚构角色与城市地图。第三轮补上曲式的时间轴玩法：教材六个部分现在全部有可玩房间，共 15 间；营造司只剩加兰特图式一间仅讲解；诗文分析没有做进房间，只在讲解卡里提了一句。这两种情况都在游戏内与结局文案中明示。

## 锁定维度

| 维度 | 锁定内容 |
|---|---|
| 平台与运行时 | 静态网页，浏览器直接运行；无构建、无后端、无外部依赖；本轮在沙箱 HTTP 预览中验证 |
| 目标运行环境 | 桌面浏览器，1280 宽为主；键盘与鼠标都能操作 |
| 市场、语言与受众 | 简体中文界面；受众为学过基础乐理、想练严格对位的人；信息密度中等偏高，术语保留英文原名 |
| 类型与先例 | 规则解谜＋城市探索。先例借用：数独式"约束满足＋即时校验"、音乐教育软件的音高试听、学院制 RPG 的城区推进。不借用任何他作的界面与素材 |
| 体验重心 | `hybrid`：判定由规则引擎裁决，叙事负责给每个知识域一个利害关系与一个说话的人 |
| 核心玩家动作 | 在空谱位放置音高、在环上拼音阶、在账页上续和声、在环上重排音集、提交验收 |
| 空间形态 | 两级：五度环城市地图，六城区；进入城区后是单屏工作台 |
| 美术与完成度 | 铜版雕版乐谱质感，米白纸张、墨黑、赭红批注；`targetFinish` = `playable-prototype`，不冒充成品美术 |
| 内容尺度 | 全年龄；无成人内容；无真实在世人物；不使用他作角色与界面 |
| 核心代入感 | 玩家是记谱学徒，名字不写在谱上；替五个师辈把散落的知识写成可用的谱；情绪峰值在最后一页署名的时刻 |
| 时长与预算 | 24 个房间，其中 15 个可玩、9 个只有讲解卡；单局 40–60 分钟；单人；买断/付费 `N/A`；本次预算为单轮会话内完成构建与实机验收 |

## 明确非目标

- 不做题库式选择题。加兰特图式与诗文分析只做讲解卡：图式要靠真实演奏辨认伴奏型态，合成骨架听不出原型与例示的差别，硬做会退化成看图识记。
- 不做加兰特图式与诗文分析的可玩化，它们需要真实演奏与文本，本轮只做讲解卡。
- 不做第三、第四类对位与四声部数字低音的玩法。
- 不做随机生成旋律并自动评分（判据必须可复现，随机内容会破坏"提交验收"的可信度）。
- 不做账号、排行榜、联机、付费。
- 不做移动端专门适配。
- 不接入生成式模型来"评音乐好坏"；所有裁决由确定性规则给出。

## 未确认假设

| 假设 | 推荐依据 | 影响范围 |
|---|---|---|
| 玩家已具备五线谱与音程基础 | 教材本身面向大学一年级乐理课 | 不做乐理教学引导层，只做术语悬浮说明 |
| 界面语言只做简体中文 | 对话语言为中文 | 若需英文版，术语表已在 SOURCE_BIBLE 中统一 |
| 只复用教材的固定旋律与规则文本，不复用其图片 | 教材为 CC BY-SA，复用需署名并以同协议发布 | 已在其许可范围内属性和声明；谱面由本作自行绘制 |
| 第二类对位作为进阶关的深度足够 | 弱拍经过音第一次引入不协和音，是规则维度的真实跃迁 | 后续若要加深，优先做第四类（留音）而非增加关卡数量 |
| 五个虚构角色与城市设定全部原创，不映射任何真实历史人物或机构 | 教材是通用乐理，没有叙事可依附；虚构人物只承担"谁在教你"和"谁的利害"两件事 | 若用户要求贴史实，需整体重写角色层 |
| 教材术语保留英文原名并配中文用词 | 对照教材原文与现有翻译习惯 | 若要求纯中文术语，需改 SOURCE_BIBLE 的术语表 |

## 待决阻断项

无。四项重大分岔（平台、核心玩法、真实人物与版权、成人内容）均不需要用户裁决：材料本身就是开源教材，核心玩法直接来自教材练习，不涉及真人，全年龄。
