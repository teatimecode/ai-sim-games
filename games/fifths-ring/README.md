# 五度环 · Fifths Ring

一座由音程承重的城。把开源乐理教材《Open Music Theory》改造成可玩作品的完整实现。

玩家是记谱公会的学徒：先捏一个纸偶，然后在六个城区里用拼、补、平、测、听五种动作，把教材散落的规则写成一册谱，最后在终页署名。

## 启动

纯静态，无构建、无依赖、无网络请求。

```bash
cd app
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080/`。

任何静态服务器都可以（nginx、`npx serve` 等），只要 `app/` 作为站点根目录。页面用相对路径引用 `styles.css` 与 `game.js`，放在子路径下也能跑。

## 声音

游戏里所有声音都由浏览器 Web Audio 实时合成，**不加载任何音频文件，也不用 CDN**。浏览器不允许自动播放，页面加载时不会发声，第一次点按钮才会启用。

顶栏右上角有一个声音状态：`待启用 / 可用 / 已暂停 / 不支持 / 异常`，图标加文字，不靠颜色区分。点它打开诊断面板，可以做三件事：

- **启用声音**：在真实点击里创建或恢复音频上下文。
- **测试声音**：放两声短提示音，然后问你「我听到了 / 没听到」。前者只说明调度成功，后者才说明真的出声。
- **复制诊断**：把状态、上下文状态、时间、可见性、错误摘要复制出来。不含设备型号、完整 UA、凭证或存档内容。

手机上没声音时，先看面板里的「人耳确认」，再按提示查媒体音量、静音/勿扰、蓝牙输出和页面是否在前台。

## 地图与校记页

地图中心的常音可以听：点「听常音」会响一条低频持续音，还没校完的城区越多，这条音越不干净；六区都校完后它才是纯的。离开地图会自动停，不会在背景里一直响。

通关后在终页可以「打印 / 存为 PDF」或「下载校记页」，得到一张单页，含化身、六枚印记、六条校记、姓名或留白。文件在本地生成，不上传。

## 没声音时先查什么

音频面板里的「没听到」会展开排查清单：iPhone / iPad 先看机身侧边的响铃/静音开关与控制中心静音模式，再看媒体音量、蓝牙或耳机输出、页面是否在前台。面板会明说一句「网页无法可靠读取这个开关，只能手动确认」，也不会把静音误判成音频文件或 CDN 的问题。技术状态正常但你没听到时，会先给一句「这多半是设备或输出端问题」，再列清单。

## 掌握度与三关巡演

每间可玩房记三档掌握：理解 = 用提示或出过违规后通过；熟练 = 零提示、零违规通过；迁移 = 在巡演里零提示、零违规通过，且逐级上升、不回退。证据都来自实际行为，不按通关次数升级。

地图上的「复习巡演 · 三关」是入口；不足三间时按钮禁用并说明「先在地图里任选一间校完」。每关上方会写为什么选它：薄弱项补哪一层、熟练项稳手感、跨域项换城区（可做变式的房会用变式题）。

巡演结算会给出三关、提示次数、预测准确率、掌握变化与下一建议，并说明掌握度的证据来源。巡演从已校过的房生成三关：一关薄弱项、一关熟练项、一关跨域迁移项。跨域项优先选能做受控变式的房：音阶与调性罗盘会把整道题整体移调两个半音，规则只看音程，因此有解性不变，题目抬头会标「变式」。迁移只在跨域项零提示零违规通过时授予。组合按存档确定性排序，只轮换起点，不会随机出没验证过的题。中途退出会把进度存档，地图上显示「继续巡演 2/3」。三关走完给提示总数、每关掌握变化和下一步建议。不足三间时按钮禁用并显示已有数量。

## 亲和度收尾

前两关各加一条白话解释：石头就是音高，五度环是按五度排的一圈；拍是心跳，小节是循环。失败时先给一行「你刚做了什么、断在哪」，再接规则批注。每间房通关后可以「存这张校记卡」，导出单页 HTML，含化身、房名、城区、掌握度与该校记。

## 房间口径

全部 27 间 = 19 间主线可玩 + 8 间仅讲解。逐间清单见 `design/ROOM_INVENTORY.md`。

## 结算里的纪念卡

通关结算把校记卡做成可选奖励，不是存档：先一行说明「含 Avatar、掌握度与校记的单页，可打印或分享；不是存档，进度已自动保存」，点「带走这张校记卡」在原位置展开预览，预览下方再给「打印 / 预览」与「下载 HTML」。下载后会在卡内回一行状态，说明文件名与格式，被拦截时指向打印另存。主按钮始终是「下一关」。

## 体验切片：预测 / 局部对照 / 分级解释

对位、和声、曲式、音集各一间房（`r-cp1`、`r-func`、`r-theme`、`r-normal`）在任务卡下方多了一个「先猜一下」面板，四个题型各不相同：对位猜先出哪类冲突，和声猜功能走向，曲式猜第一次重复的位置，音集猜共同音个数。可以跳过，不参与判定，也不影响通关与印记。

对位、和声、音集三间把固定旋律、和弦进行、整组音一起上移两个半音；曲式用原房间的小节材料拼出 A–B–A，第一次回归落在第 7 小节。四题的答案都由数据生成并用原判定器校验过，不是只改题干。变式房标题带「· 变式」。

失败时动作区多一个「对照这一处」，只比第一处差异：显示「你写的 / 参考」的局部内容，不给完整答案。批注默认只显示一句人话，规则与出处收在「展开规则与出处」里。

## 我的校记档案

地图和终页都有入口，不强制跳转。页面按掌握层级分四栏列出已完成的房间，每间显示任务要点、我做的摘要、提示次数、修正次数、是否走过迁移题；没有记录就写「未记录」。可以按城区和层级筛选，每间有「再练一遍」回到原房，不影响主线进度。

档案页顶部有「下一次复习（最多 3 项）」：按掌握证据排序，每项写清原因与动作——未记录就「开始原题」，用过提示就「少提示再练」，熟练就「挑战迁移题」，已迁移就「复听或自由复习」。每项可去练或「这次不练」，结果只写进本地复习记录，不动主线。

有暂停中的巡演时，档案页会显示「未完成的巡演 · 停在第 k / 3 关」和继续入口。

每张房卡还带一行复习摘要：复习次数、原题/迁移各通过几次、跳过几次、最近一次的时间与结果（通过时标零提示或提示次数，并显示掌握层级变化）。点「展开复习记录」可看最近三条。档案顶部总览显示已复习房间数、复习通过次数与迁移通过次数。

巡演历史保留最近三次：走完或中途退出、三关与分类、提示数、预测命中、掌握变化。没有历史不造条目。

## 本关成果卡

结算里的卡改为「本关成果卡」，内容来自真实存档与判定：房名与城区、第几关/共几关、本关任务、实际做法（已选音级、节奏构成、对位完成与违例数、和弦链、调性路径、排列/共同音、曲式标签）、掌握层级与提示修正次数、一句白话学习点。未署名显示「记谱学徒（未署名）」并说明终页可署名；未选校记显示「尚未添加校记」并说明何时添加。

## 测试

```bash
node tests/check.js
```

当前 490 条断言全过，覆盖：房间与教程卡完整性、对位四关可解性、和声局面合法性、音集与曲式数据一致性、调性罗盘最短步数、推荐下一关、化身与提示的源码守卫。

只需要 Node，不需要安装依赖。

## 玩法

| 城区 | 可玩房间 | 玩家做什么 | 判据 |
|---|---|---|---|
| 采石场 | 5 | 在五度环上选七块石；在桥板上铺时值 | 音级集合与主音；每小节时值之和与分组落音 |
| 石作 | 4 | 在残缺的对位谱上补写第二声部 | 十七条严格对位规则逐音判定 |
| 议事厅 | 4 | 续和弦；在五度圈上走最短的转调路线 | 功能方向与倾向音解决；最短步数 |
| 营造司 | 3 | 听一段短文，在时间轴上贴标签、点结构点、切分界 | 标签、位置、边界全对 |
| 边区 | 2 | 把音集转到最紧处、点出共同音 | 最小跨度与交集 |
| 市集 | 1 | 接上循环和声的下一步 | 循环位置 |

另有 9 间仅讲解房间，覆盖节拍、音程、四声部、终止式、副属与转调、加兰特图式、十二音、流行曲式。每间都有讲解卡：三条要点、教材原文引用、章节出处。

每个房间首屏有四层：任务卡（目标／步骤／完成条件）、进度行、作答区、按钮区（先听材料／作答／提交验收）。侧栏的「怎么玩」随时可重开，学徒头像旁的提示按三档给：重述目标 → 高亮区域 → 只示范第一步。

## 目录

```
app/      静态应用（index.html / styles.css / game.js / pacture-artifact.json）
design/   游戏设计、信息架构、美术方向、概念选型、实现约定、来源考据、内容路线图
qa/       验收记录，含未验证项
tests/    规则与内容自检（node tests/check.js）
```

后续内容扩展的取舍与下一版范围写在 `design/CONTENT_ROADMAP.md`，体验与审美升级的想法写在 `design/EXPERIENCE_UPGRADE.md`，四个岗位的优化评审写在 `design/OPTIMIZATION_REVIEW.md`。

## 已知限制

- 加兰特图式与诗文分析只有讲解卡，没有玩法。
- 校记四选（修正／保留／并记／留白）只记录选择，没有后续剧情差异。
- 音频未经人耳复核，只验证了信号与调度。
- 未做触屏手势适配。
