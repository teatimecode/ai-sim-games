# 受控迁移切片：设计先行，暂不改代码

范围：从对位、和声、曲式、音集各挑一间，验证「预测 → 操作 → 局部对照 → 解释 → 受控迁移」这一条链路。**本文件只是方案与测试计划，尚未实现**，不要当成已完成。

## 为什么先不改

现有系统能做的迁移只有一种：巡演里换上下文、零提示通过。真正换材料（换调、换节奏型、换音集）需要改动房间数据与判定入口，属于结构性改动，按本轮要求不擅自扩大。

## 五段式与现有能力对照

| 段 | 现状 | 缺口 |
|---|---|---|
| 预测 | 无 | 需要在提交前加一个二选一/三选一的预测卡，不判定对错 |
| 操作 | 已有 | 无需改 |
| 局部对照 | 已有对照听与首差高亮 | 需要能只对照「出错的那一小节/那一列」 |
| 解释 | 已有批注与规则出处 | 需要把解释绑到这次预测的结果上 |
| 受控迁移 | 只有巡演换上下文 | 缺换材料变体 |

## 变体设计：只做可证明有解的一种

对四间房各定义一个变体，变体答案由参考解机械变换得到，因此有解性可证明：

| 房间 | 变体 | 有解性依据 |
|---|---|---|
| r-cp1 | 固定旋律整体上移 2 个半音 | 对位规则只看音程，整体移调不改变任何音程关系 |
| r-func | 同一条功能链，主音改为上方五度 | 功能关系按音级定义，移调保持 |
| r-theme | 同一段材料的乐句切分整体后移一小节 | 只考边界判断，切分点整体平移后仍唯一 |
| r-normal | 音集整体 T3 后要求最小跨度排列 | 最小跨度在移调下不变 |

实现方式：运行时克隆房间对象，对音高字段统一加偏移，判定仍走同一个 `judge`，不新增随机数。这样"无解"在构造上不可能出现。

## 测试计划

1. 每个变体：参考解变换后必须零违例（单元测试，直接调 judge）。
2. 每个变体：随机 200 组输入中至少有一组通过，证明不是无解题。
3. 变体与原房间共用同一渲染器，快照对比 DOM 结构不变。
4. 迁移只在变体通过时授予，主线再次通过不升级、不降级。
5. 音频不可用时，五段式全部走文字，预测卡与对照条都在 DOM 里可读。

## 落地顺序

先做 r-normal 与 r-cp1 两个变体（变换最简单、判定最纯），跑通后再评估 r-func 与 r-theme。一次只动一间，避免 19 间同时改。
