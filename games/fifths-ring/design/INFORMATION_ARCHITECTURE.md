# 信息架构与用户旅程

本文件定义《五度环》的页面、路由、存档与反馈。代码实现以 `app/game.js` 为准，本文描述用户看到的结构。

## 页面清单

| 页面 | 一句话目标 | 入口 | 出口 | 关键反馈 |
|---|---|---|---|---|
| 落地页 | 让第一次来的人知道自己是谁、要做什么、下一步点哪；化身随机生成，定制是次要入口 | 首次访问自动进入；地图右上角「首页」 | 「开始旅程」或「继续旅程」进地图；「怎么玩」开说明层 | 主按钮文案随存档变化；六城区预览显示已校数 |
| 环城地图 | 选择下一个城区，看到总体进度与自己站在哪 | 落地页、房间结算、页面刷新恢复 | 点城区节点选城区；点房间行进房间 | 每个城区节点显示「已校 / 可玩」；顶栏校记计数 |
| 房间 | 完成一页任务 | 地图的房间行 | 「回到环城」返回地图；验收通过后回地图 | 任务卡、进度行、页边标记、提交提示 |
| 验收结算 | 告诉玩家这一页过没过、为什么 | 房间内提交 | 「回环城」或「回去改」 | 零违例写「无瑕」；有违例逐条列出规则与出处 |
| 终页 | 收尾并署名 | 全部可玩房间通过后，从房间返回地图 | 「署上」后回地图 | 显示「六页校记」与署名输入 |

## 路由规则

开机时按存档决定落在哪一页：

| 存档状态 | 落在 | 理由 |
|---|---|---|
| 没有存档，也没有任何进度 | 落地页 | 第一次来必须先理解这是什么 |
| 有进度，上次在房间 | 该房间 | 刷新不打断正在做的那一页 |
| 有进度，上次在落地页 | 落地页 | 玩家自己在看说明，刷新保持 |
| 有进度，其余情况 | 环城地图 | 正常续玩 |

「有进度」的判定：存档里 `started` 为真，或已有任意房间通过，或已经署名。只看是否写过存档不算有进度，避免空存档把新玩家挡在落地页外。

## 存档与清除

- 存档键只有一个，包含：各房间进度、已校房间、城区校记、署名、当前页面与房间。
- 每次渲染地图或房间都会写回一次，保证「画面看到的」和「刷新后恢复的」一致。
- 落地页不覆盖进度：它只读取进度决定按钮文案与城区预览，不清空任何东西。
- 「重新开始」必须两步：第一次点击展开确认条，写清「会清掉所有校记和进度，不能撤销」，第二次点「确定清除」才真正清空；点「取消」回到原状。

## 化身与印记

- 落地页显示身份卡：自动生成的化身、六枚印记槽、主按钮「开始旅程／继续旅程」；「换一个随机形象」与「改形象」是次要按钮，展开后才出现五组选项。
- 形象由存档种子生成，刷新保持；清除进度后重新生成。首次进入不展开定制，也不要求先确认。
- 地图上化身贴在当前城区节点的右下角，侧栏写「你在这里」并列出六枚印记槽。
- 房间侧栏是化身的半身像与「让学徒提示」，三档提示依次重述目标、高亮区域、示范第一步，不替玩家选值。
- 拿到城区印记时插入一次「校记」选择（修正／保留／并记／留白），只影响记录方式，不影响判定。
- 终页显示化身、个人符号、六枚印记、六个城区的记法，以及姓名或留白。
- 节奏房（采石场两间）：两条桥面 + 音符/休止素材板；点小节选中，点素材铺上去；「试听整段」是提交前置，铺满且判定通过才能呈交。

## 地图常音与校记页

地图中心的常音可点「听常音」：低频持续音，未校完的城区越多差频越明显，六区清完后变纯。离开地图或页面隐藏即停止，不支持 Web Audio 时只显示文字。

终页提供「打印 / 存为 PDF」与「下载校记页」：单页 A4，含化身、六枚印记、六条校记、姓名或留白与完成数，纯本地生成。

## 声音入口

顶栏右侧常驻一个声音状态按钮，文案随状态变化：待启用、启用中、可用、已暂停、不支持、异常。点击打开诊断面板，里面只有确实能检测到的事实：Web Audio 是否支持、音频上下文状态、最近启用与测试时间、页面可见性、是否由手势触发、创建次数、最近错误摘要。面板提供「启用声音」「测试声音」「复制诊断」三个动作。

测试音之后会问「我听到了 / 没听到」。上下文 running 只证明调度成功，不代表扬声器真的出声，所以人耳确认单独记录；选「没听到」会给出手机端排查顺序。页面从后台回来时只重读状态，不自动播放。

## 声音

落地页写明：建议戴耳机、页面不会自动发声、第一次点按钮之后浏览器才解锁音频。开机流程不调用任何发声函数，避免被浏览器拦截时静默失败。

## 无障碍

- 每个页面只有一个 h1，品牌名用非标题元素承载。
- 主按钮文案明确写出动作：开始旅程 / 继续旅程 / 确定清除 / 取消。
- 所有按钮与可点元素有键盘焦点环；清除确认出现时焦点移到「确定清除」，取消后焦点回到「重新开始」。
- 三个宽度 768 / 1024 / 1280 均无横向溢出。


## 掌握度与巡演的位置

- 地图：`#tourHost` 一行汇总「理解 / 熟练 / 迁移」，下面是「三关巡演」或「继续巡演 k/3」。
- 城区面板：标题下一行该区三档计数。
- 房间：`#tourBar` 显示「巡演 2/3 · 熟练项 · 房名 · 本关提示 n 次」，附「下一关」与「退出巡演」。
- 结算：pass 时追加「掌握 · X（证据）」一行。
- 校记页：署名下方一行三档计数。


## 亲和度元素的位置

- 任务卡：`.mission-plain` 在目标句下面，只有前两关有。
- 批注列表：#markList 的第一项是 `.fault-note`，之后才是「第一处不同」与规则批注。
- 结算：pass 时多一个「存这张校记卡」，生成 Blob 下载，不联网。


## 结算页层级

1. 主标题与批注（我做到了什么）
2. 掌握度一行（证据）
3. 纪念卡区块：说明 → 「带走这张校记卡」→ 展开预览 → 「打印 / 预览」「下载 HTML」→ 状态回执
4. 动作区：`下一关：<房名>`（主按钮，btn-ink）、`回环城`
