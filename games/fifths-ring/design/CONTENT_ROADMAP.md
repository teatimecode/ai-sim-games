# 内容与可玩性扩展路线图

本文件回答一个问题：在现有 26 个房间（17 可玩、9 仅讲解）之上，下一批内容该做什么、按什么顺序做、什么不做。所有判断基于当前 `games/fifths-ring` 的真实代码与教材章节，不是愿望清单。

## 0. 现状盘点

| 玩法 | 房间数 | 动词 | 判定性质 | 听觉参与 |
|---|---|---|---|---|
| 拼音阶 | 3 | 选石 + 定主音 | 集合相等 | 试听整组 |
| 补对位 | 4 | 逐音放置 | 十七条规则 | 每音即时发声 |
| 平/续和声 | 2 | 选和弦 | 三条倾向规则 | 整和弦 |
| 调性罗盘 | 2 | 走一步 | 最短路径 + 首断点 | 新旧主和弦 |
| 听曲式 | 3 | 贴标签 / 点结构点 / 切分界 | 标签与位置 | 逐小节播放 |
| 测音集 | 2 | 转起点 / 点共同音 | 最小跨度 / 交集 | 播放集合 |
| 循环续写 | 1 | 接下一步 | 循环位置 | 整和弦 |

缺口很清楚：**教材"基础"部分里的时值与拍号没有玩法**，四声部与图式也还只有讲解卡；同时没有任何复习或迁移机制，玩家打完一遍就结束。

## 1. P1 选题：十二音序列锻造台 vs 节奏桥梁

| 维度 | 十二音序列锻造台 | 节奏桥梁 |
|---|---|---|
| 学习目标 | 十二音各用一次；P/I/R/RI 变换保持音级集合 | 时值相加等于拍号；强弱分组；切分的合法性 |
| 玩家动词 | 在 12×12 网格里排列音级，再选一种变换 | 在节拍网格上放置或删除音符与休止 |
| 音乐输入/输出 | 输入一条序列，输出序列及其变换的播放 | 输入拍号与小节数，输出一段可播放的节奏型 |
| 判定模型 | 唯一性（每个音级恰好一次）+ 变换一致性 | 每小节时值总和、重音位置、切分是否跨拍并解决 |
| 失败反馈 | 指出重复或缺失的音级，以及变换后对不上的位置 | 播放到断点停下，标出第几小节第几拍，说明多/少几拍 |
| 复用组件 | 环节点、和弦/序列播放、结算 | 时间轴渲染、播放调度、提交结算、三档提示 |
| 内容生产 | 手工写若干序列与变换题 | JSON 写目标节奏骨架与允许操作 |
| 相对成本 | 中（新网格 + 变换 UI + 序列播放） | 低到中（网格 + 打击音色，其余复用） |
| 风险 | 听觉反馈弱，容易退化成排列题；玩家可穷举 | 音色单一；切分判定容易过严 |
| MVP 房间数 | 2（已落地：4/4 把桥板铺满、6/8 复拍子的桥） | 2 |

**推荐：节奏桥梁。**

理由不是它更简单，而是它满足"听见决策后果"这条更硬的标准。节奏错一拍，播放时立刻能听出来；序列排错一个音，除非玩家有绝对音感，否则几乎听不出来，判定就会退化成"按规则排列"。另外它填补的是教材基础部分唯一没有玩法的区域，而十二音那章已有讲解卡兜底。

十二音不废弃，降为 P1-b：等节奏切片验证了"网格 + 播放断点"这套骨架后再做，可以直接复用网格与断点反馈。

## 2. P1 切片规格：节奏桥梁（MVP 已落地）

> 状态：两间房已实现并通过验收，见 `design/GAME_DESIGN.md` 的「节奏桥梁」一节与 `qa/verification.json`。下面是立项时的规格与最终实现的对照。

| 项 | 内容 |
|---|---|
| 学习目标 | 时值相加＝拍号；强拍与弱拍的分组；切分必须跨过拍点并解决 |
| 玩家动词 | 在网格上点格子放音符、再点取消；可切换音符与休止 |
| 音乐输入/输出 | 输入拍号与小节数；输出一段可播放的节奏，配合一个固定低音或节拍器 |
| 判定模型 | 每小节时值总和等于拍号；重音落在分组位置；切分音必须跨过拍点并在下一拍解决；错误定位到第一个不满足的小节与拍位 |
| 失败反馈 | 播放到断点停下，网格上标红该拍，文字写"第 2 小节第 3 拍多了一拍"这类具体缺口 |
| 复用组件 | 时间轴渲染、播放调度、提交结算、三档提示、化身反馈 |
| 内容生产 | 每个房间一份 JSON：拍号、小节数、目标节奏骨架、允许的时值集合 |
| 相对成本 | 低到中：一个新网格组件 + 打击音色，其余全部复用 |
| 风险 | 音色单调导致疲劳；切分规则若写得太死会只剩唯一答案 |
| MVP 房间数 | 2（已落地：4/4 把桥板铺满、6/8 复拍子的桥） |
| 验收门槛 | 成功、失败、刷新恢复、音频非静音、768 宽不溢出，五条全过才进主分支 |

房间设计：

1. **四拍与三拍**：4/4 与 3/4 各给一小节骨架，玩家补全剩余时值。目标是听出分组差异。
2. **切分**：给一条平直节奏，要求改成切分版，判定跨拍与解决；同一目标允许多种写法，只要满足约束。

多解分层：合法但不流畅（时值都对但重音混乱）→ 有效（重音正确）→ 流畅（重音正确且切分解决自然）。结算给出层级，而不是对错二元。

## 3. P2 深化现有玩法

### 3.1 第三、第四类对位

| 项 | 内容 |
|---|---|
| 学习目标 | 留音的准备—挂留—解决；拍位语义 |
| 玩家动词 | 逐音放置，并给不协和音指定"准备音" |
| 输入/输出 | 固定旋律 + 玩家声部；每音即时发声 |
| 判定 | 现有 17 条 + 留音三段式（前拍协和、强拍不协和、下行级进解决） |
| 失败反馈 | 指出挂留未解决或解决方向错 |
| 复用 | 对位谱面、调色板、规则引擎、提示 |
| 内容生产 | 写固定旋律与参考解 |
| 成本 | 中：需要新的时值语义 |
| 风险 | 规则叠加后新手更难，需要更好的分档 |
| MVP 房间数 | 2（已落地：4/4 把桥板铺满、6/8 复拍子的桥） |
| 验收 | 正例/反例各一条，参考解可被求解器验证 |

## 4. P3 高成本项（有前置条件才做）

### 4.1 受控四声部排练室

先只开放一个声部，玩家补完后再逐步开放第二、第三个。判定必须复用现有和声规则，不允许另写一套。前置条件：和声判定先抽成可复用的四声部版本，并证明不会误判。

### 4.2 微型作曲 / 联合校记

让玩家把已学的几类决策串成两小节。**前置条件**：四声部排练室稳定运行一个版本，且判定器能对整段而非单点给结论。否则不做。

## 5. 可玩性系统

| 系统 | 做法 | 不做什么 |
|---|---|---|
| 3 关复习巡演 ✅ 已落地 | 从已通关房间取三个：薄弱、熟练、跨域；组合确定、只轮换起点 | 不做每日任务、签到 |
| 本地掌握度 ✅ 已落地 | 每间房记三档：理解（有提示/违规）、熟练（零提示零违规）、迁移（巡演零提示零违规） | 不做全局等级、经验值 |
| 受控变式种子 | 用种子生成变式，同一玩家可重放，测试可复现 | 不做真随机抽题 |
| 多解质量分层 | 非法 / 有效但笨重 / 有效且流畅，结算给层级 | 不做唯一答案匹配 |

禁止：金币、体力、签到、排行榜、无意义刷取。任何新系统若既不增加音乐决策，也不让玩家听见后果，不进入范围。

## 6. 如何避免题库化

每个新切片至少要覆盖"感知 → 操作 → 因果反馈 → 迁移"里的三步，只换题干或换调号不算新内容。

检查表（新内容上线前逐条回答）：

1. 玩家在操作前需要先听什么？听不出差别就不该做。
2. 玩家的操作改变了音乐结构的哪一部分？
3. 做错了，播放会在哪里断、听感差在哪？
4. 同样的知识，玩家能不能在另一个城区用上？
5. 是否存在两种都合法但质量不同的写法？结算有没有区分？

现有 17 间里，拼音阶三间共用同一动词，已用两间只读房隔开；新内容不应再出现连续三间同动词同反馈。

## 7. 下一版本范围

**做**：节奏桥梁 2 间 + 掌握度记录 + 3 关复习巡演的最小版。✅ 已落地，并补了亲和度三条。

**不做**：四声部、微型作曲、十二音、真实录音相关的图式侦探、任何经济系统。

**指标**：新玩家从落地页到完成第一间的比例；每间首次通过率；复习巡演的重玩率；提示三档的使用分布（若第三档使用率过高，说明任务卡不够清楚）。

## 8. 顺序

1. 节奏桥梁切片（2 间）+ 验收五条
2. 掌握度记录（理解/熟练/迁移三档）
3. 3 关复习巡演（复用变式种子）
4. 终止式车站（低成本，补听辨）
5. 第三、第四类对位（需要新时值语义）
6. 十二音锻造台（复用网格与断点反馈）
7. 图式侦探与四声部（需要真实素材与判定器重构）
