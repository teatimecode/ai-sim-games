# 四岗位联合评审：按青少年反馈优化

评审输入：上一轮青少年视角的批评 + 现有 19 间可玩房、6 城区、5 角色的真实实现。本文按四个岗位分头给结论，最后合并成一张可执行清单。

## 总判断

青少年说的三件事都成立，而且指向同一个问题：**这游戏的好东西都藏在第 40 秒之后。**

第一声在点击试听后，第一次"我做到了"在十次点击之后，第一个能带走的东西在通关之后。前 40 秒只有文字和一张纸。三份岗位的改法最后都落到"把好东西提前、把反馈变具体"。

## Game Designer

### 读数

- 从落地页到第一次有效操作，是"读文案 → 开始 → 地图 → 选城区 → 选房间 → 读任务卡 → 第一次点击"，五屏，估计 40–70 秒。
- 首间房 `十二块石头` 要求选七块石并定主音，可失败。没有任何"保证的成功"。
- 19 间房全部是同一节奏：任务卡 → 操作 → 提交。没有释放段。
- 没有任何可见的"我做得好"信号：无计时、无评级留存、无分享。

### 问题

按本岗位的 onboarding 检查表，三条不达标：核心动词不在 30 秒内出现、首次成功不保证、首局结尾没有钩子。青少年说的"打开像作业本"，根因就是这三条。

### 改法

1. **首胜前置**：在第一次进入任何房间前，插一段 20–30 秒的「试音」——环上随便点，点一个响一个，没有任何判定和按钮文字，最后一句"这就是常音"就结束。做成房间内的浮层，不新增房间，不动 19 间计数与印记逻辑。
2. **节奏表**：把 19 间按认知负荷重排，每两间高负荷后接一间低负荷或纯叙事。

   | 时段 | 内容 | 负荷 |
   |---|---|---|
   | 0–1 分 | 试音 + 节奏桥 | 低 |
   | 1–4 分 | 拼音阶两间 | 中 |
   | 4–8 分 | 对位两间 | 高 |
   | 8–9 分 | 校记选择 | 无 |
   | 9–13 分 | 对位两间 + 和声 | 高 |

3. **掌握度可见但不排名**：每间房通过时在页面上盖一枚章——一次通过且零违例是朱印，重抄后通过是墨印。只影响这一页的样子，不做全局分数。
4. **首局钩子**：第一个城区清完时的校记选择，结尾加一句"下一城的人已经在等"，具体点名。

## Level Designer

### 读数

- 地图是唯一的空间。六个节点等权，只有数字不同；已校与未校除了计数没有视觉差别。
- 房间页除标题外没有城区特征，六区的房间看起来一样。
- 下一站有按钮，但没有空间指向。

### 改法

1. **已校与未校用形状区分**：修好的节点换成有棱线的"砌合"状态，未校的保留裂纹。不靠颜色，靠轮廓。
2. **地图会变**：每清一个城区，该节点补上一道线，中心常音变纯一点。这是空间叙事，比任何台词都直接。
3. **下一站给一个空间指针**：不是按钮，是地图上从化身指向目标节点的一条细线，鼠标移上去显示房间名。
4. **房间页的分区感**：四个城区用不同的页眉分隔符与页脚编号样式，让玩家一眼知道自己在哪一区。
5. **回流聚焦**：从房间回到地图时，刚变化的节点闪一次（一次，不循环）。

## Narrative Designer

### 读数

- 五个角色各有一句台词和一张讲解卡，声线靠文案工作者自觉，没有写下来的支柱。
- 专有名词密度高：常音、校记、学徒、印记、乐长、公会。前两间房就把这些全抛出来。
- 校记四选是唯一的叙事选择，但它的回响只在终页。

### 改法

1. **词汇降密**：前两间房只允许出现「常音」和「校记」两个词，其余下沉到讲解卡。
2. **声线支柱**：给五人各写一条——词汇、句长、避谈什么、默认是否直说。例：维斯只用短句和砌墙的比喻，从不谈自己的耳朵。
3. **选择的回响**：选「保留」的人，该城区角色在下次见面时会提一句；选「留白」的，终页那一行留空。已有数据结构，只缺台词分流。
4. **环境替代说明**：城的修复状态由地图承担，不用旁白解释世界观。

## Technical Artist

### 读数

- 全部资产是 SVG/CSS/WebAudio，没有外部文件。性能瓶颈不在贴图，在节点数与同时发声的振荡器。
- 触控目标偏小：音高按钮高约 30px，普通按钮约 32px，低于移动端 44px 的常用下限。
- 一个和弦是 4 个音 × 4 个泛音 = 16 个振荡器；曲式房整段播放会一次排队上百个。
- 动效只有当前谱位的呼吸与播放头，其余全静。

### 改法

1. **触控预算**：所有可点元素最小 44×44，间距不小于 8。只改 `padding` 与 `min-height`，不改布局。
2. **发声预算**：同时振荡器上限 96，超出按最旧优先回收；整段播放改为按小节分批调度，不再一次性排满。
3. **动效预算**：每屏最多 3 个动效，时长 120–220ms；`prefers-reduced-motion` 时全部关闭。
4. **打印样式**：`@media print` 单独一页——A4、无背景色、字号不小于 10pt，作为「校记页」的交付形态。
5. **节点上限**：曲式房 15 小节、节奏房 18 槽的节点数要保持在 300 以内，超过就分页渲染。

## 合并清单（P0 已落地）

| 优先级 | 改动 | 岗位 | 成本 | 验收 |
|---|---|---|---|---|
| ✅ P0 | 试音浮层：第一次进房前 20–30 秒自由试听 | Game | 低 | 已落地：12 块石头可点，只发声不判定，可跳过，不改房间计数 |
| ✅ P0 | 触控目标 ≥44px | Tech Art | 低 | 已落地：768 宽实测 44px，横向溢出 0 |
| ✅ P0 | 失败页「听修好的版本」 | Game | 低 | 已落地：失败后出现按钮，播放该类房间标准答案 |
| P1 | 印章：朱印/墨印 | Game | 低 | 一次通过为朱印，重抄为墨印；刷新保持 |
| P1 | 地图节点修复态 + 下一站指针 | Level | 中 | 清区后节点轮廓变化；指针指向正确房间 |
| P1 | 常音的呼吸 | Level + Tech | 低 | 未校城区越多拍频越明显；可关 |
| P1 | 词汇降密与声线支柱 | Narrative | 低 | 前两间房专有名词 ≤2 个 |
| P2 | 校记四选的角色回响 | Narrative | 低中 | 选「保留」后该区角色下次提一句 |
| P2 | 打印校记页 | Tech Art | 低 | 打印预览单页、无溢出 |
| P2 | 一区一音色 | Tech Art | 低 | 两区同一段音阶可听出差异 |

## 待决

- 试音浮层是"每局一次"还是"每次新房间一次"。建议每局一次，否则会烦。
- 印章是否计入终页。建议只留在房间页，不堆到终页，避免信息过载。

## 不做

不做计时、不做排行榜、不做成就墙、不做每日任务。青少年要的是"我做到了"的凭据，不是被比较。
