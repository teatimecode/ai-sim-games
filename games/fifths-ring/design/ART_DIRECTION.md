# ART_DIRECTION — 雕版谱页

## 视觉命题

一整页纸就是画面。玩家看到的不是"游戏界面"，而是一张摆在乐长书桌上的练习谱：米白手工纸、墨黑符头、赭红铅笔批注。所有 UI 元素必须像是画在这张纸上的东西，禁止出现悬浮卡片、玻璃拟态、渐变光晕。

依据出自材料本身：教材的谱例全部是雕版风格的印谱，`Graphics/` 里数百张谱例共用一套墨线语言。本作不复用这些图片，但沿用它的视觉语法：细而均匀的线、无阴影、靠留白与字重分级。

## 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸 | `#f3ede0` | 主背景，带极轻的纸纹噪点 |
| 纸暗部 | `#e7dfcd` | 谱表底纹、分区 |
| 墨 | `#211c18` | 谱线、符头、正文 |
| 墨淡 | `#6f6455` | 次级文字、谱号 |
| 赭红 | `#a3392a` | 玩家当前操作、批注、违例标记 |
| 靛青 | `#2f5d63` | 通过、正确、允许 |
| 金褐 | `#8a6d3b` | 完成度、署名 |

只允许赭红与靛青两个强调色同时出现，且不同时用于同一元素。

## 字体

- 标题与固定旋律署名：衬线，`Songti SC, Iowan Old Style, Georgia, serif`，字重 600，字距略增。
- 正文与批注：衬线同族，字重 400，行高 1.7。
- 术语与音名：等宽或小型大写字距加宽，`ui-monospace`，用于区分"这是术语"。
- 不引入外部字体文件，避免离线不可用。

## 谱面

双谱表，谱线间距 12px，线宽 1px，颜色为墨的 55% 不透明度。谱号手绘感由路径近似实现，不使用字体字符。符头为椭圆形，整体高 13px，宽 10px，倾斜约 20 度。空谱位为赭红描边空心符头，当前谱位加一圈呼吸光晕，周期 2 秒。小节竖线为细实线，贯穿两谱表，颜色为墨的 30%。

## 批注语言

违例不弹窗、不变红闪屏，而是像老师批改：在该音上方画一个赭红短标记，页边出现一行批注，格式为「第 5 音 · 平行五度 · 见 firstSpecies.md:45」。批注写在纸的右侧留白区，垂直对齐到对应小节。

## 运动

只允许三种运动：符头放入时的 120ms 下沉、批注的 200ms 淡入、当前谱位光晕呼吸。禁止位移过场、禁止缩放弹跳。整页没有任何循环动画超过一个。

## 完成页

过关时纸面整体轻微抬升，页脚出现一行金褐色署名与"第 N 页已校"印章式文字。不使用粒子、彩带。

## 禁止

不使用教材的位图谱例、不模仿任何现有商业音乐游戏的界面、不使用真人肖像、不使用 3D 与拟物乐器。
